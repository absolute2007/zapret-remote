# Zapret Remote

Локальный прокси-мост под Windows для мобильного клиента **Happ** (iOS и Android) и **Telegram** внутри домашней Wi-Fi сети, пропускающий трафик телефона через уже работающий на ПК `zapret` (`winws.exe`) и `TgWsProxy`.

## Принцип работы

Приложение поднимает локальный входящий узел на базе `xray.exe` (`XTLS/Xray-core`, `VLESS` поверх `TCP` без избыточного шифрования для LAN: `encryption=none`, `security=none`) и отправляет исходящие соединения напрямую через системные сокеты (`outbound: freedom`). Драйвер `WinDivert` запущенного на ПК `zapret` прозрачно перехватывает исходящий трафик на сетевом интерфейсе компьютера.

- Никаких TUN/TAP-драйверов и правки системного прокси Windows или таблиц маршрутизации.
- Оригинальный `zapret` по умолчанию работает полностью изолированно (мониторинг процессов `winws.exe` строго в режиме чтения).
- Для повседневного запуска и выключения права администратора не требуются.

## Возможности

- **Автозагрузка `xray.exe`:** при первом запуске (если `bin/xray.exe` отсутствует) автоматически скачивает актуальный официальный релиз `Xray-windows-64.zip` с GitHub (`XTLS/Xray-core`).
- **Поддержка Happ (iOS и Android):**
  - Вкладка `1. Happ (VLESS)` — постоянный сгенерированный `UUID`, автоопределение реального LAN IPv4 (с фильтрацией виртуальных адаптеров WSL/Hyper-V/Docker/VirtualBox/VPN и ручным выбором интерфейса), крупный QR-код (с увеличением по клику) и кнопка копирования ссылки `vless://`.
  - Вкладка `2. Маршрут Happ` — генерация диплинка `happ://routing/onadd/...` (`FakeDNS + DoU 1.1.1.1`, блокировка IPv6 `2000::/3`, локальная сеть напрямую).
  - Блокировка QUIC (`UDP 443`) и подавление AAAA/HTTPS (qType 28/65) DNS-ответов для корректной работы `winws.exe` на мобильном трафике.
- **Мост для Telegram (`TgWsProxy`):** если на ПК запущен `TgWsProxy`, приложение считывает его локальный порт и секрет из `%APPDATA%\TgWsProxy\config.json` (read-only) и пробрасывает в LAN через отдельный порт с готовой ссылкой и QR-кодом `https://t.me/proxy?...`.
- **Брандмауэр Windows без постоянного UAC:** проверка правила в реестре без прав администратора и однократное создание/удаление разрешающего правила для локальной подсети по кнопке через UAC.
- **Диагностика и безопасная автонастройка `zapret`:**
  - Проверка доступности `www.youtube.com`, локального CDN (`googlevideo.com`) и выявление редиректов `302` на внешние заблокированные узлы через локальный `xray.exe`.
  - Автоподбор стратегии `list-google.txt` (с обязательным сохранением оригинала в `zapret-backup.json` до любых правок, не затрагивая Discord и остальные правила) и кнопка отката к оригинальной конфигурации `zapret`.
- **Системный трей и управление процессами:** сворачивание в трей, раздельные иконки состояния, привязка `xray.exe` к Windows Job Object (`KILL_ON_JOB_CLOSE`) для защиты от зависших процессов.

## Требования

- Windows 10 / 11 (x64)
- [.NET 8.0 Desktop Runtime (x64)](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
- Установленный и запущенный на ПК `zapret` (`winws.exe`)
- Опционально: `TgWsProxy` для проксирования Telegram

## Быстрый старт

1. Скачайте `ZapretRemote.exe` из раздела [Releases](../../releases) и поместите в отдельную папку.
2. Запустите `ZapretRemote.exe`. Нажмите **«Включить прокси-мост»** (при первом запуске автоматически скачается `xray.exe` в подпапку `bin`).
3. Если индикатор брандмауэра жёлтый, нажмите **«Разрешить»** рядом со строкой брандмауэра (однократный запрос UAC).
4. На телефоне в **Happ**:
   - На вкладке `1. Happ (VLESS)` нажмите `+` -> **Сканировать QR-код** и отсканируйте QR.
   - Для оптимальной маршрутизации на вкладке `2. Маршрут Happ` скопируйте ссылку `happ://` и импортируйте её в **Happ -> Настройки -> Маршрутизация -> Импорт**.
5. При необходимости для Telegram перейдите на вкладку `Telegram (TgWsProxy)` и отсканируйте `t.me/proxy` QR камерой.

## Ограничение провайдеров (ТСПУ)

Если на ПК ролики на YouTube запускаются мгновенно (форматы `AV1/VP9`), а на iOS часть видео зависает или уходит в долгую загрузку, откройте **«Диагностика»**: некоторые провайдеры полностью фильтруют TLS к внешним зарубежным серверам `googlevideo.com` (`74.125.*` / `173.194.*`) по IP/TLS на уровне ТСПУ после 302-редиректа с локального кеша, что невозможно обойти локальным `zapret` без внешнего сервера.

## Сборка из исходников

Требуется [.NET 8 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/8.0):

```powershell
dotnet publish src/ZapretRemote/ZapretRemote.csproj `
  -c Release `
  -r win-x64 `
  --self-contained false `
  -p:PublishSingleFile=true `
  -o dist
```

Быстрая самопроверка CLI (проверяет конфиги, генерацию QR, запуск/остановку `xray.exe` и сквозной VLESS-запрос):

```powershell
.\dist\ZapretRemote.exe --self-test
```
